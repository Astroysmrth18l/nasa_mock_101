# SPHEREx Sky Explorer & Planet X Finder 🪐✨
### NASA Space Apps Challenge 2026

A high-tech, futuristic space-exploration web application built with a Techfest IIT Bombay inspired dark-mode neon UI and space-gaming anime aesthetic.

## 📂 Repository File Structure
- `index.html`: Contains the core multi-page interface layout, navigation links, and functional views (Home, Explorer, Comparator, Ranking, Provenance).
- `style.css`: Custom stylesheet featuring glassmorphism cards, glowing cyan neon borders, and smooth transitions.
- `script.js`: Client-side script handling dynamic route switching, spectral band calculations, and the background 3D particle starfield.

## 🚀 Quick Start
1. Clone or download this repository.
2. Open `index.html` directly in any modern browser or run it via a live server (e.g., VS Code Live Server).
